# **App Name**: Telegram Auto Finder

## Core Features:

- Search Interface: Display a search interface with filters for car color, model, type, and price range.
- Results Display: Use fake service to mimic Telegram messages based on user selected filters.
- Card Layout: Display results in a clean, card-based layout optimized for Telegram's mini-app environment.

## Style Guidelines:

- Primary color: Soft gray (#F0F0F0) for background.
- Secondary color: White (#FFFFFF) for card backgrounds and content areas.
- Accent: Teal (#008080) for interactive elements and highlights.
- Card-based layout for search results to maximize readability
- Use clear and simple icons for filters and categories.
- Subtle animations for search loading and filter interactions.
